## 输入与比较设计

使用 make_example() 的 default_rng(0)，X(3,4)、Wq/Wk/Wv 各 (4,4)，全部 float64。三个权重分别使用 max(abs(W))/127 的 scale，整数范围 [-127,127]。保留 Wo、FFN、残差、LayerNorm 和 eps。

compare_quantization(x,parameters) 先运行浮点基线，创建 quant_parameters=parameters.copy()，然后仅把 Wq/Wk/Wv 替换为各自反量化的浮点数组。两路均调用原 transformer_block()，使用其返回的中间值比较 Q/K/V、S、P、PV、注意力输出、H1、F、H2。独立检查原 X 与所有基线参数未改动，未量化参数在两路相同。实现扩展位于 software/int8_quantization.py；原 Block 源码未修改。

## 第 2 课：手算与存储

沿用第 1 课 W=[[-1.27,0.237],[0.504,1.27]]，取 X=[[1,2]]。原投影为 [[-0.262,2.777]]；量化反量化后为 [[-0.270,2.780]]。投影最大误差约 0.008，大于权重最大误差约 0.004。代码 check_projection_example() 用这些手算值核对。

令 DeltaW=W_hat-W，则 DeltaQ=X@DeltaW。每个投影元素的误差界为 sum_k(abs(X[i,k]))*s/2，再加浮点舍入容差。本例 sum(abs(X))=3，理论界 0.015。正式三矩阵比较也逐行检查该界，keepdims=True 形成 (3,1)，向四个输出列广播。

| 三张权重的表示 | 实测数据字节 |
|---|---:|
| 原 float64 权重 | 384 |
| int8 权重数据 | 48 |
| 三个 float64 scale | 24 |
| int8 权重及 scale 合计 | 72 |
| 运行时恢复的 float64 权重 | 384 |

代码用数组 nbytes 统计，scale 显式打包成含三个元素的 float64 数组。只计整数权重数据的比值是 8；包含 scale 后为 5.333333333333333。统计范围是 Wq/Wk/Wv，不是整个 Transformer。运行期同时存在原权重、整数数组、反量化数组与检查快照，72 字节不能当作进程峰值内存。

## 第 3 课：误差传播

前向路径：

    X -> Q/K/V -> S -> P -> PV -> attention_output
      -> X + attention_output -> H1 -> FFN -> F
      -> H1 + F -> H2

仅三张投影权重发生变化。Wo 与 FFN 权重虽保持相同，它们接收到的输入已改变，输出会相应变化。LayerNorm 包含每行均值、方差和除法；各阶段误差不要求单调增加或减小。下面分别比较每阶段自己的两路结果，不把不同阶段的误差大小当作统一模型质量指标。

| 阶段 | 最大绝对误差：Python 3.13.3 |
|---|---:|
| Q | 0.009999300907530984 |
| K | 0.010488656852627676 |
| V | 0.010652438595531999 |
| S | 0.01002347101953971 |
| P | 0.0011734236485539395 |
| PV | 0.008350414876074408 |
| attention_output | 0.02883671952128264 |
| H1 | 0.0040312603904523285 |
| F | 0.02145591809366998 |
| H2 | 0.0014781696627168273 |

例如原 H2 最后一行约 [0.778276,0.789227,-1.662067,0.094564]，量化权重版约 [0.778606,0.789956,-1.661649,0.093086]；输出形状仍为 (3,4)。

误差度量为 max(abs(float_trace[name]-quant_trace[name]))，对本阶段整个矩阵的全部元素取最大值。权重/投影检查使用可推导误差界；最终 H2 如实报告，原始要求未给定最终质量阈值。本轮未测试真实模型准确率或运行速度，计算路径为反量化后的 float64 矩阵乘法。
