## 实验设计

每张 Wq/Wk/Wv 分别使用一个正的 scale，即按矩阵的对称量化。三张矩阵共三个 scale，零点为 0，整数范围采用 [-127,127]：

    s = max(abs(W)) / 127
    q = clip(rint(W / s), -127, 127).astype(int8)
    W_hat = q.astype(原浮点类型) * s

rint 做最近整数舍入；恰好在中点时采用 NumPy 的 ties-to-even 规则。clip 在转换类型前限制范围，最后才转 int8。全零矩阵约定 s=1、q 全零，反量化仍全零，以避免除零。普通非零矩阵必须保持题目给定的 max(abs(W))/127 规则。

保持 X、Wo、FFN 权重/偏置、残差、LayerNorm、eps 与浮点基线相同。用 parameters.copy() 创建另一路参数字典，只替换三个权重为反量化数组，不原地改动浮点基线。

计算两次：

    float_output, float_trace = transformer_block(x, parameters)
    quant_output, quant_trace = transformer_block(x, quant_parameters)

quant_parameters 中 Wq/Wk/Wv 是 W_hat。INT8 数组用于存储，前向乘法使用反量化后的浮点数组。本实验考察权重存储与量化误差；运行速度分析按这一实际计算路径说明。

## 验证顺序与通过标准

1. 检查量化数组 dtype 为 int8、形状不变、值在 [-127,127]；scale 为正有限数，反量化值有限。
2. 全零矩阵精确还原；正负最大幅值可映射到 +127/-127；预备手算例子与公式一致。
3. 对非零有限权重，重建最大绝对误差应不超过 s/2 加浮点舍入容差。容差在实现时根据原 dtype 和权重量级确定。
4. Q/K/V 和两路 H2 均为 (3,4)，每一路注意力概率非负、行和约为 1，全部输出有限。
5. 三个 Q/K/V 误差分别计算 max(abs(base - quant))，H2 误差同样记录。量化有信息损失，不沿用融合实验中要求近乎完全一致的判据，也不把“误差必须非零”当要求。
6. 用投影误差界辅助定位：若本矩阵 scale=s，则 |(XW-XW_hat)[i,j]| <= sum_k |X[i,k]| * s/2，加相应浮点容差。
7. 最终 H2 的实测误差如实记录，原始要求未给固定质量阈值。不能先编造“输出误差小于 0.01”等通过线；S、P、注意力输出、H1、F 可用于定位变化，不能据权重误差直接推定最终 H2 的固定界。
8. 存储统计使用实际数组 nbytes；scale 按明确的打包数组 dtype 计数。Python 对象、字典与运行期临时数组不混入权重数据字节。
9. 浮点基线参数保持不变；Wo 和 FFN 等未量化参数在两路相同。

## 存储预期：必须区分统计范围

当前三张 (4,4) 权重合计 48 个元素：

| 统计对象 | 预计数据字节 |
|---|---:|
| 原 float64 三张权重 | 48*8 = 384 |
| int8 三张权重数据 | 48*1 = 48 |
| 三个 float64 scale | 3*8 = 24 |
| int8 权重及 scale 合计 | 72 |

只比较权重数据是 8 倍缩减；含 scale 为 384/72，约 5.33 倍。以上是本机当前 float64 基线和这三张权重的统计，不代表整个 Transformer 的存储缩减倍数。所有数值在正式实现后用 nbytes 核对。

反量化后的三张 float64 W_hat 本身另占 384 字节；如果同时保留原权重、q、scale 和 W_hat，运行时内存不能按 72 字节报告。72 字节描述可保存的 INT8 权重及 scale 数据，不是完整程序的峰值内存。
